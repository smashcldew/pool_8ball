# 8 號球線上對戰 🎱

純前端的 8-ball 撞球遊戲，可放在 GitHub Pages。房主產生**邀請碼**，朋友輸入後透過 WebRTC（PeerJS）**點對點直連**對戰，不需要自己架後端伺服器。

- 📱 手機、平板、電腦都能玩（拉桿瞄準，放開擊球）
- 🤝 邀請碼 / 邀請連結對戰，或單機兩人輪流
- ⚖️ 標準 8 號球規則：分組、犯規、自由球、勝負判定
- 🔒 規則由房主端判定，並擋下對手的不合法動作

## 線上部署（GitHub Pages）

1. 在 GitHub 建一個 repo（例如 `pool`），把這些檔案推上去：
   ```bash
   git remote add origin https://github.com/<你的帳號>/pool.git
   git push -u origin main
   ```
2. 到 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，存檔。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/pool/`。
4. 打開網址 →「建立房間」→ 把邀請碼或邀請連結傳給朋友即可對戰。

> 這是純靜態網站，GitHub Pages 免費方案就夠用。

## 本機試玩

因為用了 `<script src>` 載入檔案，直接用 `file://` 開也可以，但建議起一個小伺服器：
```bash
cd pool
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000
```
同一台電腦測連線：開兩個分頁，一個建立房間、一個貼上 `?room=邀請碼` 的連結即可。

## 操作

| 動作 | 方式 |
| --- | --- |
| 瞄準 / 擊球 | 在球桌**按住**，往母球的**反方向**拉，越遠力道越大，放開擊球 |
| 取消這一桿 | 拉回到很近再放開，或按右鍵 / `Esc` |
| 自由球（對手犯規後） | 直接點球桌空位放置母球 |

白色虛線是母球預測路線，黃線是目標球被撞後的方向。

## 規則重點

- 開球後第一顆落袋的球決定你打**全色（1–7）**還是**花色（9–15）**。
- 打進自己的球可以**續打**；沒進或犯規就換人。
- **犯規**（母球落袋、沒碰到任何球、先碰到不該碰的球）→ 對手可把母球放到桌上任意位置（ball in hand）。
- 清光自己的 7 顆球後，再合法打進 **8 號球**就獲勝。
- 太早打進 8 號球、或打進 8 號球的同一桿犯規 → **直接判負**。
- 開球時 8 號球不慎落袋 → 放回桌面，不判負。
- （簡化版，沒有「叫袋」與開球四顆上岸等進階規則。）

## 連線說明 / 疑難排解

- 配對使用 **PeerJS 的公共雲端伺服器**只為了交換連線資訊，實際遊戲資料是兩位玩家**直接點對點**傳輸。
- **連線為什麼有時會失敗？** WebRTC 要穿過雙方的 NAT／防火牆直接打洞，成功率取決於網路環境與當下時序，所以純 STUN 下會「時好時壞」，**校園／宿舍網路**尤其明顯。另外免費公共 PeerJS 配對伺服器偶爾也會塞車或房主 ID 傳播延遲。
- 本專案已內建緩解：連不上時會**自動重試**（最多 4 次），房主端也會用最新的連線取代半開的死連線。
- **某一方當房主就連不到？** 這是嚴格 NAT 的典型不對稱現象：嚴格 NAT 的一方當房主（被連接方）時特別難被連到。**解法是設定可用的 TURN 中繼。**（註：舊的免費公共 `openrelayproject` 靜態帳密已失效，所以純 STUN 現在等於沒有中繼。）
- 要**穩定**（接近 100%），到 [dashboard.metered.ca](https://dashboard.metered.ca) 免費註冊（約 50GB／月）→ 建立一個 App → 取得 **subdomain** 與 **API key**，填進 `game.js` 最上方的 `METERED`，程式會自動取得中繼憑證：
  ```js
  const METERED = { subdomain: 'myapp', apiKey: 'abcd1234' };
  ```
  若自架或用別家 TURN，改填 `TURN` 陣列即可：
  ```js
  const TURN = [{ urls: 'turn:你的伺服器:3478', username: '...', credential: '...' }];
  ```
- 房主需保持頁面開啟等待對手加入；對手離線時會跳出提示。

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面與畫面結構 |
| `style.css` | 樣式（深色、響應式、支援瀏海螢幕） |
| `engine.js` | 物理與 8 號球規則引擎（不依賴畫面，可單獨測試） |
| `session.js` | 對戰流程與網路同步（房主權威、防作弊） |
| `game.js` | 繪圖、拉桿操作、PeerJS 連線 |
| `test/engine.test.js` | Node 單元測試（引擎 + 同步，共 20 項） |

## 測試

```bash
node test/engine.test.js
```
涵蓋擺球、隨機 400 桿壓力測試（無 NaN、不出界、必定停下）、物理正確性、全部規則分支，以及房主／挑戰者逐桿同步與防作弊。

## 技術說明

- 固定時間步長（1/480 秒）模擬，雙方用相同輸入可得一致結果；最終仍以房主結算為準並廣播校正，避免累積誤差或作弊。
- 無框架、無建置流程，三個 `<script>` 直接跑；唯一外部相依是 CDN 上的 PeerJS。
